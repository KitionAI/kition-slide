# Attribution

Every asset Kition Slide includes, bundles, embeds at build time or shows in its documentation,
with its author, source and license. The policy is in [AGENTS.md](../AGENTS.md) §1. `cargo xtask
assets` fails if a file under `assets/` or `examples/` is missing from this table.

Kition Slide contains **no Microsoft, Adobe, Avid or Autodesk iconography, images, fonts, themes,
templates or other assets**. Its themes, colour schemes, layouts, preset-shape geometry, sample
deck and UI icons are original work (drawn or generated in code).

## Embedded from kition-fonts (`KITION_FONTS_DIR`)

[KitionAI/kition-fonts](https://github.com/KitionAI/kition-fonts) is the one checkout both this
repository's build and the web editor use, next to this repository (`../kition-fonts`; per-file
author, source, SHA-256 and license are in kition-fonts' own ATTRIBUTION.md). Not committed here
(`.gitignore`, `web/.gitignore`).

- `crates/support/fonts/build.rs` embeds every family in its `fonts/manifest.txt` (and
  `fonts/latin-manifest.txt`, if kition-fonts ever adds one) into native builds (including
  `bindings/headless`), except the families it excludes (Adobe-derived, AGENTS.md §1.1); web
  (wasm32) builds embed only Inter Regular/Bold/Variable and BIZ UDPGothic Regular of them. Today
  that is every family in the table below for native builds, and Inter (variable) for the web
  engine (kition-fonts does not hold BIZ UDPGothic).
- The web editor's build (`web/scripts/build-engine.sh`) separately copies Droid Sans Fallback and
  the metric-compatible Carlito, Caladea, Arimo, Tinos and Cousine faces from the same checkout,
  each with its license file, into the package's `fonts/`; the editor hands them to the engine's
  `addFont`.

[NOTICE](../NOTICE) carries each font's copyright line and the license texts the package does not
ship as separate files.

| Family | License | Notes |
|---|---|---|
| Droid Sans Fallback | Apache-2.0 | Simplified and Traditional Chinese, Japanese kana; also served to the web engine from `fonts/` |
| Inter (variable) | OFL-1.1 | Native builds; the only kition-fonts face the web engine embeds |
| Lora, JetBrains Mono, Bricolage Grotesque, Noto Color Emoji, Ma Shan Zheng | OFL-1.1 | Native builds |
| Carlito, Caladea, Arimo, Tinos, Cousine | OFL-1.1 | Native builds; also served to the web engine from `fonts/` (metric-compatible stand-ins for Calibri, Cambria, Arial, Times New Roman, Courier New) |
